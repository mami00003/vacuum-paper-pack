掃除機の紙パック逆引き ／ シャープ・マキタ

シャープとマキタの掃除機の紙パック

シャープは機種が分からなくても「ヨコ型（紙袋式）全機種」用から選べます。マキタは紙パック式モデルだけが対象で、カプセル式には紙パックがありません。

シャープ — 機種が分からなくても選べる

シャープは機種が分かれば型番で、分からなければ「ヨコ型（紙袋式）全機種」用から選べます。

  • EC-CR1 / XR3 / XR2 / XR1 / WR2 / KR3 / KR2 / KR1 → EC-330PN
  • EC-KR70A / KR50A → EC-530PN
  • ヨコ型（紙袋式）・機種が分からない → EC-17PN / EC-16PN
    どちらも公式に「シャープヨコ型タイプ掃除機（紙袋式）全機種」用と書かれています。EC-17PN は5層で捕集性能が高く、EC-16PN は3層です。

「全機種用」が存在するのは6社でシャープだけです。手元に機種名が残っていないときは、ここから選べます。

マキタ — 紙パック式のモデルだけが対象

マキタは充電式クリーナの紙パック式モデルが対象です。カプセル式のモデル（CL280FD など）には紙パックがありません。

シャープ・マキタが「純正以外」について書いていること

シャープだけは、発煙・発火ではなく保証の話として書いています。6社のなかで書き方が一社だけ違います。

マキタ
「クリーナの紙パックは、本機性能を維持するための大切な機能部品です。そのため、純正以外の紙パックを使用した場合はモータの発煙、発火する恐れがあります。」
出典
シャープ
「純正品以外の別売オプション品・消耗品のご使用に起因する不具合については、製品の保証期間内であっても有償となりますので、ご注意ください。」
出典

6社ぶんの逐語は「互換品を使っていいのか」にまとめています。
