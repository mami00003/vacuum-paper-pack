メーカー別 — 適合の決まり方

「機種型番を入れれば紙パック型番が出る」という表は、公式情報だけでは作れません。6社のうち機種を大量に列挙しているのは東芝だけだからです。各社が公式に示している決まり方をそのまま書きます。

パナソニック

パナソニックは掃除機の機種ではなく、紙パックの形状で適合が決まります。いま入っている紙パックの形か、取扱説明書の指定型番で選んでください。

  • M型Vタイプ → AMC-HC12 / AMC-NC6 / AMC-S5
  • LM型Vタイプ → AMC-NK5 / AMC-K5
  • S型 → AMC-U2
  • ハンドクリーナー用 → PHC-PA1KD / PHC-PA2KD

日立

日立は掃除機の種類で決まります。キャニスター（CV-で始まる機種）は4種類のどれでも使え、ちがいは集じん性能と価格です。

  • キャニスター（CV-） → GP-2000FS / GP-130FS / GP-110F / GP-75F
    公式の逐語：「パックフィルターは、GP-2000FS・GP-130FS・GP-110F・GP-75Fがご使用いただけます。」 上から順に集じん性能が高く、価格も高くなります。
  • スティック（PKV-） → GP-S120FS
  • こまめちゃん → GP-S35F

東芝

東芝は機種型番から引けます。本体の底面や背面のシールにある「VC-」から始まる型番を入れてください。

掃除機の機種型番を入力して引きます。公式FAQが列挙している機種は下の一覧にすべて載せています。

三菱電機

三菱電機は掃除機の形で決まります。横形（キャニスター）は3種類のどれでも使え、ちがいは消臭・抗菌の仕様です。

  • 横形（キャニスター） → MP-9A / MP-7A / MP-3A / MP-2
    公式は対応機種を列挙せず、使えない機種のほうを挙げています。次の機種には使えません：TC-NS、AR、970JP、960P、950、951、300、301、310P、311P、350J、355JP。
    TC-NS／TC-AR には MP-30 を使います（公式注記で TC-AE／TC-AF／TC-AG タイプにも装着可能）。
  • TC-NS / TC-AR → MP-30
  • ハンディ・スティック → MP-25
    公式が列挙している対応機種：HC-P1、HC-P2、HC-P10、HC-P30、HC-A1、HC-A2、HC-A3、HC-A5、HC-B30、HC-B70、HC-BA70、HC-BA30、HC-BB70、HC-BB30、HC-BC70、HC-BC30
  • コードレススティック HC-JK2E → MP-STC1-5P

シャープ

シャープは機種が分かれば型番で、分からなければ「ヨコ型（紙袋式）全機種」用から選べます。

  • EC-CR1 / XR3 / XR2 / XR1 / WR2 / KR3 / KR2 / KR1 → EC-330PN
  • EC-KR70A / KR50A → EC-530PN
  • ヨコ型（紙袋式）・機種が分からない → EC-17PN / EC-16PN
    どちらも公式に「シャープヨコ型タイプ掃除機（紙袋式）全機種」用と書かれています。EC-17PN は5層で捕集性能が高く、EC-16PN は3層です。

マキタ

マキタは充電式クリーナの紙パック式モデルが対象です。カプセル式のモデル（CL280FD など）には紙パックがありません。

  • CL107FD / 4076DW → A-48511
